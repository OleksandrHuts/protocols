# Протоколи безпілотних систем · інтерактивна схема

Локальна лекційна сторінка: узагальнений квадрокоптер, клікабельні компоненти й з'єднання, фізичний і логічний рівні, популярні варіанти, типові помилки.

## Відкрити

Відкрийте `index.html` у браузері. Сервер та інтернет не потрібні.

## Що є на сторінці

- 22 з'єднання між компонентами дрона.
- Для кожного з'єднання: переваги, недоліки, коли доречно, стійкість до завад/вразливості.
- Лівий сайдбар із розбором; зайві рядки «Рівні», «Швидкість», «Кабель» прибрано.
- 34 протоколи/варіанти у матриці з пошуком.
- Клік по лінії відкриває:
  - фізичний рівень: роз'єм, дроти, напруга, швидкість, duplex, термінація;
  - логічний рівень: кадри, адресація, CRC, канали, час;
  - популярні варіанти;
  - типові помилки;
  - джерела.
- Клік по компоненту підсвічує всі його зв'язки.
- Фільтри за класами: керування, ESC, сенсори, телеметрія, відео, companion, CAN, сервіс.
- Матриця протоколів із пошуком.
- Темна технічна схема, адаптивна верстка.

## Навігація

- `#link=gps-fc` - відкрити конкретне з'єднання.
- `#part=fc` - відкрити компонент.
- `Скинути` - прибрати вибір і фільтри.
- `Esc` - закрити матрицю.

## Важливе про рівні

Сторінка навмисно розділяє:

1. Фізичний рівень - електрика й роз'єми.
2. Транспорт/шина - UART, I2C, SPI, CAN, USB, RF.
3. Логічний протокол - SBUS, CRSF, DShot, UBX, DroneCAN.
4. Застосування - MAVLink, NMEA, RTCM, Remote ID.

Тому `SBUS` не є «радіолінком», `UART` не є протоколом, а `MAVLink` не є фізичним інтерфейсом.

## Структура

- `index.html` - розмітка.
- `style.css` - темна тема й SVG-стилі.
- `data.js` - компоненти, з'єднання, протоколи.
- `app.js` - рендер SVG, вибір, фільтри, матриця, hash-навігація.

Дані відокремлені від логіки: новий протокол або з'єднання додається в `data.js`.

## Обмеження

Це узагальнена навчальна схема, а не pinout конкретної плати. Реальні рівні, роз'єми, baud і порядок пінів залежать від FC, RX, ESC, GPS і версії прошивки. Для монтажу перевіряйте документацію конкретного виробу.
